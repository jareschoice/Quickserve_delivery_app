                        🌐 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════

1. BACKEND SERVER (Port 5555):
   ────────────────────────────────
   - Runs: node backend/server.js
   - URL: http://192.168.29.104:5555
   
   - Serves TWO things:
     a) API endpoints at /api/*
     b) Static files from event-frontend/
   
   - Example routes:
     ✅ http://192.168.29.104:5555/api/vendors        (API)
     ✅ http://192.168.29.104:5555/event-frontend/home.html  (Web)
     ✅ http://192.168.29.104:5555/event-frontend/css/home-style.css  (CSS)

2. ADMIN PANEL (Port 3000):
   ────────────────────────────────
   - Runs: npm run dev (from admin-panel/)
   - URL: http://localhost:3000
   
   - Completely separate React application
   - Uses Vite for development
   - Proxies API calls to backend on port 5555
   - Does NOT serve event-frontend files

3. EVENT-FRONTEND:
   ────────────────────────────────
   - Static HTML/CSS/JS files
   - Served BY the backend server
   - Accessed at: http://192.168.29.104:5555/event-frontend/
